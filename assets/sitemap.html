What changed

  • H1 rewrittenGeneric category → category + brand + Tarragona + Cataluña. The three keywords now ranking first are all in it.
  • Duplicate H2 removed“Único centro termal de / en Tarragona” ran twice on one page, one preposition apart.
  • Empty heading removedOne H2 contained only the word “hotel”.
  • FAQ promoted H3 → H2Answers rewritten to lead with the answer in 30–50 words, so an assistant can quote the block whole.
  • 10 H2 + 3 H3 → 13 clean H2Every heading now owns one intent, with H3 clusters beneath it.
